<objective>
Fix the GUI 14-segment display truncating the exponent of large scientific values.

Phase 65-01 (ADR v4.3-005) made `FACT(27..=69)` return real factorials, so large
magnitudes (`1.088886945E28`, `1.711224524E98`) became reachable in the GUI for the
first time. The GUI 14-segment display (`Display14Seg.tsx`) has exactly 12 cells and
silently truncates longer strings; `format_hpnum` emits `1.088886945E 28` (14 cells),
so the exponent was cut off — caught during MATH-01 UAT.

Implements DISP-04 (Option A, HP-41-authentic, ADR v4.3-006): a 12-cell LCD formatter
that drops the "E" and right-justifies the exponent. GUI main display only; the wide
CLI / stack displays keep the "E" form.
</objective>
