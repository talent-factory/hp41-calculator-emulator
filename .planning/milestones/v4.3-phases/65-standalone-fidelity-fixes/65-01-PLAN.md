<objective>
Extend `HpNum` from a bare `Decimal` wrapper to a normalized `{ mantissa: Decimal, exponent: i8 }` representation covering the full HP-41 range ±9.999999999E±99, so that `FACT(27..=69)` returns the correct 10-significant-digit factorial in scientific notation instead of `HpError::Overflow`.

Implements MATH-01 (D-01, D-02, D-03, D-04). This is the heavy plan. The three DISP fixes are independent light plans in Wave 2.

Purpose: The emulator currently overflows above the `rust_decimal` ceiling (~7.92E28); FACT is merely where that limitation is user-visible. This change gives the whole engine authentic HP-41 range while preserving 10-sig-digit decimal fidelity (no f64 stored representation).
Output: New HpNum struct + arithmetic + serde, updated `format_hpnum`, fixed `op_fact`, ADR amending the Frozen Invariant, and golden/proptest/serde tests.
</objective>
