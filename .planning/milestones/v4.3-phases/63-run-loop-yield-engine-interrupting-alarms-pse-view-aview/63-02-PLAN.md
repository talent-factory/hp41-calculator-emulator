By keeping the entire interrupt/yield mechanism inside the core `run_loop`, criteria 1/4/5 become reachable in BOTH frontends with thin glue (SC-4).
Output: A working synchronous yield/interrupt boundary; all 16 VALIDATION core scenarios GREEN.

This plan owns `program.rs` EXCLUSIVELY (no other plan in any wave touches it) — avoids the shared-git-index race (reference_parallel_wave_index_contention). It reads/writes `state.pending_interrupt_depth` (declared by 63-01 in state.rs) but does NOT touch state.rs, preserving wave isolation.
