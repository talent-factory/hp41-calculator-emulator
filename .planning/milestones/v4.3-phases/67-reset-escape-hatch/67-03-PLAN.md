<objective>
Add two Tauri v2 commands — `reset_soft` and `reset_full` — modeled on the
existing `save_state` command (commands.rs:656-677). Each locks `AppState`, calls
`state.soft_reset()` / `state.memory_lost()`, then IMMEDIATELY persists to the
resolved autosave path WHILE STILL HOLDING the mutex (overwrites the autosave so
recovery survives restart and beats the auto-save thread), and returns the
`CalcStateView`. No new enum crosses IPC. Register both in `generate_handler!`,
create permission TOMLs, and reference them in `capabilities/default.json`.

Purpose: the GUI/iOS frontend (Plan 04) calls these from the ON-key handler.
Output: two commands + permissions + a round-trip autosave-overwrite test.
</objective>
